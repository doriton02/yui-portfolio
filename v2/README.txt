結-YUI- ネイル　サイトファイル一式（ポートフォリオ用サンプル）

■ ファイル構成
index.html      … トップページ
menu.html       … メニュー・料金ページ
css/style.css   … デザイン（色・文字・レイアウト）
images/         … 写真（WebP形式）

■ 確認方法
index.html をブラウザで開くと表示できます。
（フォントはGoogle Fontsから読み込むため、インターネット接続が必要です）

■ よく変更する箇所
・色：css/style.css の先頭 :root にある --accent（臙脂色）など
・メニューと料金：menu.html の <ul class="prices"> の中
・営業時間・アクセス：index.html の id="access" の中
